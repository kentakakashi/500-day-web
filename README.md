# Our Little Forever — 500 Days

A romantic, responsive anniversary experience built with React and Vite.

## Run locally
1. Install Node.js 20 or newer.
2. Run npm install.
3. Run npm run dev and open the local URL shown in your terminal.

## Personalize
Add photos in public/memories and update src/data/memories.js. Replace the starter letter in src/App.jsx with your own words. Music control is currently a placeholder until an audio file is wired in.

## Deploy
Connect this repository to Netlify. netlify.toml configures the Vite build.
